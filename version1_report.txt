# AI Research Paper Intelligence Platform — Complete Project Report

## 1. Project Title

# AI Research Paper Intelligence Platform using Semantic Search, Knowledge Graphs, and AI Retrieval

---

# 2. Project Overview

This project is an AI-powered research paper analysis platform designed to process IEEE-style research papers and provide intelligent semantic understanding of uploaded PDFs.

The system extracts structured sections from research papers, performs semantic chunking, generates embeddings using transformer models, builds dynamic knowledge graphs, enables AI-based question answering, generates semantic summaries, and visualizes advanced evaluation analytics.

The platform acts as an intelligent research assistant capable of understanding engineering and scientific papers semantically instead of simple keyword-based retrieval.

---

# 8. Session Management Logic

## Current Storage Mechanism

Uses:

```js
sessionStorage
```

instead of:

```js
localStorage
```

Reason:

* refresh resets project
* no stale paper data
* clean demo state

---

## Session Behavior

### During Session

* upload persists
* tab switching persists

### Browser Refresh

* resets everything
* graph cleared
* summaries cleared
* evaluation reset
